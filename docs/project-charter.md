# Project charter

## Purpose

Demonstrate a layered Java/Spring Boot REST API and an Angular application structure through a product-and-category catalog domain.

## Intended audience

- Reviewers assessing Java, Spring Boot, PostgreSQL, Docker, and Angular breadth.
- Learners who want a compact reference for a catalog CRUD application.

## Current scope

- Product and category CRUD endpoints with pagination.
- DTO, service, repository, and controller layers in the backend.
- H2-backed local/test profile and PostgreSQL-oriented runtime configuration.
- Docker assets for backend, frontend, and PostgreSQL.
- Angular routing, component, model, and service scaffolding.

## Explicitly outside the current scope

- A connected and complete frontend experience.
- Authentication, authorization, and production security hardening.
- A CI/CD pipeline, Kubernetes deployment, or a production support commitment.

## Success measure

The repository is understandable as an honest alpha-stage stack demonstration, with clear next steps rather than unsupported production claims.
