## Status

The Spring Boot API is the implemented portion of the project. The Angular application is scaffolded but is not integrated with the API and is not production-ready. Treat this repository as an alpha learning project and a portfolio example of the stack, not as a deployable product.

## Documentation boundary

These documents describe the repository as found. They do not change application behavior, runtime configuration, dependencies, or deployment claims.
